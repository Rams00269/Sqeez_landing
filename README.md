# Sqeez_landing

Landing page for Squeez: the page where a venue's empty tee times get filled by guests who name a price.

- `index.html` is the whole page (plain HTML, CSS and JS, no build step).
- `assets/mascot/` is Squizzle, the lemon guide. It is a reusable module: see `assets/mascot/README.md`.

## Run it

Open `index.html` in a browser, or serve the folder with any static server.

## Deploy

It is a static site. On Vercel, import this repository and keep the defaults (no build command, no output directory).
